# Key Quest

A progressive typing game for kids, in a single HTML file. Open `index.html` in any browser.

## Levels

1. **Home Row** — `asdfghjkl;'`
2. **Top Row** — `qwertyuiop`
3. **Bottom Row** — `zxcvbnm,./`
4. **All Keys** — the whole keyboard, including numbers and punctuation

Each level runs 18 rounds that mix real words with random letter strings drawn
from that row's keys, so there is plenty of practice per row. An on-screen
keyboard highlights the next key and colour-codes each key by which finger to
use. Progress, stars, and the sound setting are saved in the browser.
